# XGamingLab 3.0.0 · GPU Virtual PWR

This branch carries the exact source archive split into Git blobs because XGamingLab is not yet a standalone repository.

The app implements and measures this path:

CPU/Ether/XI logical state + delta -> GPU Virtual compact relation -> QSSD revisions -> REgraphics minimal input -> physical GPU -> presentation.

The new physical GPU timer is split into shadow, scene and composition passes. The PWR bytes metric has an explicit denominator: the legacy exact per-instance vertex-input payload for eligible compact objects/passes. It is not a global GPU-work percentage.

The PWR ABBA campaign alternates the previous explicit instancing route and the compact GPU Virtual route under the same scene settings. No resolution, object-count or effect reductions are implicit.

No merge is requested automatically.
