The C63 compact-index profile completed a genuine billion-instruction block and a further 1.5-billion block. The latter clean state is count 38,208,013,374, SHA-256 `de0b06b3b6bf77d0c538c805e875e633f4801c13d9737e35623c51dd234f2125`. A subsequent attempt genuinely executes 401,120,549 instructions before unsupported `0x7e30d8e7` at PC `0x73b58af940`: FADDP S7,V7.2S. That failed tail is diagnostic, never a continuation source. Independent original-C63 replay of exactly the prefix reproduces a clean state at count 38,609,133,923, SHA-256 `d047254c86848ccb3b48ffcebc1a56721e9ff4ae97264ac00aaadd392b5ee6db`, with original C46 source/security gates passed.

Implement all ten scalar S/D forms in this architectural class: FADDP, FMAXP, FMINP, FMAXNMP and FMINNMP. Capture the source vector before an aliased scalar write. Use the existing validated scalar arithmetic helper for the two source elements in architectural order, then the existing scalar write that clears all remaining vector bits. Keep FP access gating, rounding, NaN ordering, signed zero and cumulative status semantics. Reject reserved FADDP encodings before FP access. Retain the original S/D arithmetic policy; FP16 arithmetic is not added or advertised.

The observed V7 has raw S values `0x3cb851e8` and zero, with all upper bits zero, FPCR=0 and FPSR=17. The expected result is exactly `0x3cb851e8`, so the genuine crossing leaves the entire FPU section unchanged. It must still execute one instruction, advance PC by four and counter phase 38 to 39. This identity example alone is not proof of arithmetic: the full suite checks nonidentity sums, extrema, both source orders, infinities, quiet/signaling NaNs, subnormals, signed zero, overflow and cumulative flags.
