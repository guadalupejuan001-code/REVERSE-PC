# C56: scalar and vector floating-point absolute difference

The verified C55 million-instruction probe reached count 28,503,274,546, SHA-256 `d0b239d74cbff5952484de8cecb7e9f4c67c302b76f232c2fe59450471d889a7`. The original GPU decoder exported a real 800x600 scanout; every pixel is currently black. This is GPU initialization evidence, not completed Android boot or visible framework UI.

A further genuine cycle advanced 16,953,089 instructions before unsupported `0x7ea1d400` at PC `0x5cb422aeac`: FABD S0,S0,S1. Actual S0=24.0 and S1=30.0, so S0 must become 6.0 with upper bits cleared; existing FPSR=16 is preserved. The diagnostic tail SHA is `44523662be0303d569781727191e170e4f83f03d83496a6417a16c3e678ea665`. A separate clean replay of precisely this prefix reproduced every original byte, passed every source/security gate and completed its budget. This clean execution is the continuation source; failed tails are never admitted.

Implement all five allocated S/D forms: scalar S/D and vector 2S/4S/2D. Perform the original rounded FP subtraction before clearing the result sign. Source vectors are captured before destination writes; inactive scalar/vector upper bits clear. Existing NaN, FZ/DN, rounding, cumulative FPSR and FP access trap behavior applies. The unallocated vector 1D form rejects atomically.

Local Release and UBSan each passed 22,241 cases / 1,492,247 checks. Tests cover all source register pairs and destination aliases, exact and inexact subtraction, directed rounding, signed zero, NaN payloads/signaling, infinities, overflow and subnormal inputs/results, inactive signaling NaN lanes, unchanged GPRs/core/RAM, original snapshot replay and rollback. AArch64 CI independently executes every register triple for every allocated form and additional FPCR/edge/random cases before authentic continuation. The native oracle preserves the host callee-saved vector registers.

The workflow authenticates the C55 stage-3 checkpoint and pinned native reference, independently replays the pre-FABD prefix with the reference and candidate and compares every snapshot byte. It executes exactly one FABD and checks the actual 24/30/6 operands, count/PC/subtick and all other original bytes. Bounded verified stages continue until actual completed boot and original scanout. Each verified checkpoint is uploaded before proceeding. The unchanged C53 frame executable supplies the original strict decoder.

The original compact RVG/MXIM encoding/decoders, XI/Ether authority, logical 2-GiB RAM, disk/authentication, seeded 64-instruction cadence, IRQ checks and enforcing SELinux remain unchanged. No instruction is skipped or delegated to another emulator. Completed boot still requires live system_server with Zygote lineage, framework evidence and live PID1 sys.boot_completed=1; real display content is assessed separately.
