# C57: scalar and vector floating comparisons with zero

The verified C56 million-instruction probe reached count 28,521,227,636, SHA-256 `7f64124c9eb12ab7de8a4d6bc255c9e2e1004b0824c00fa934cb4436bbef0002`. C56 CI independently reproduced the complete local checkpoints before FABD, after FABD and after this probe. Original 800x600 scanout is present but currently black; system_server and completed Android boot remain pending.

A genuine cycle then advanced 41,889,854 instructions before SurfaceFlinger reached unsupported `0x2ea0d824` at PC `0x5cb3fb76ec`: FCMLE V4.2S,V1.2S,#0.0. Both actual source lanes are positive zero. Both result lanes must therefore be all ones: V4.low=0xffffffffffffffff, V4.high=0. The previous V4.low is 0x34324241, and FPSR=16 must remain unchanged. The failed-tail SHA is `51ed845febb09172aaee9857d76b71619fc619506ef46b8c6562e66cbb0608e0`. A separate clean replay of precisely this prefix reproduced those complete original bytes, completed its budget and passed every source/security gate. Failed tails are never admitted as sources.

Implement all 25 allocated S/D forms: FCMEQ/FCMGE/FCMGT/FCMLE/FCMLT with zero, each in scalar S/D and vector 2S/4S/2D forms. Use the original FP comparison and access gate, capture inputs before writes, return full-lane bit masks and clear inactive upper bits. Ordered comparisons signal quiet NaNs; equality signals signaling NaNs only. FZ applies to original input denormals and preserves cumulative IDC. Integer GPRs, NZCV, core and RAM remain unchanged. Reserved scalar/vector width forms and the unallocated U=1 less-than form reject atomically.

Release and UBSan each passed 34,401 cases / 2,307,306 checks. An independent IEEE classification/truth-table reference covers every source/destination register pair, aliases, signed zero, infinities, quiet/signaling NaNs, subnormals, FZ/DN/rounding controls, untouched inactive signaling-NaN lanes, original snapshot replay, FP traps and rollback. CI executes the actual encodings on AArch64 hardware for all register pairs and additional edge/random FPCR cases before genuine Android continuation.

The workflow authenticates C56 stage 3 and its pinned tested native binary, replays the clean prefix with both reference and candidate and compares every original byte. It executes the actual FCMLE once, verifies source/result/PC/count/subtick and every other byte, and continues bounded verified stages. Each verified checkpoint is uploaded before proceeding. The unchanged C53 frame executable remains the original decoder.

Only the outer GitHub ZIP switches to compression level 1. On the same original 1,137,300,337-byte checkpoint, local full-input level-6 compression took 47.495 seconds (348305245 payload bytes), and level 1 took 11.051 seconds (396926777 payload bytes). This is 4.30x faster compression with a larger ZIP payload; it is not an emulator-throughput benchmark. Every original input byte was SHA-256 checked, no payload was retained, and zero guest instructions ran during this measurement. The RVG/MXIM encoding, checksums and original decoder are unchanged.

The original XI/Ether authority, logical 2-GiB RAM, disk/authentication, counter seed and 64-instruction cadence, IRQ checks and enforcing SELinux remain unchanged. No instruction is skipped or delegated to another emulator. Completed boot still requires live system_server with Zygote lineage, framework evidence and live PID1 sys.boot_completed=1; display content is reviewed separately.
