# Integración REVERSE 2.5.5 (rama de desarrollo)

Incluye Music, PRISMA/X Render e iconos, Qd Cody con verificación XI de 32 casos y Laplace X 0.2 en X MARKET.

Laplace recibe 8–220 datos históricos por entrada manual (CSV date,close_cents) y ejecuta el archivo forecast-one.xi original en NativeRuntime.execute(NativeRuntime.initialize(), source). Se usa la operación aislada experiment. No escribe la memoria del escritorio ni BBY Q/W4u, ni descarga cotizaciones.

El predictor es de un solo paso y su filtro de error histórico no representa probabilidades calibradas. Los datos de ejemplo son sintéticos. No se implementa feed bursátil ni trading.

Music tiene reproducción local, repetición e importación de audio directo HTTPS, pero no extrae audio de YouTube; bloqueo de anuncios experimental. Qd sigue limitado a plantillas de cuatro familias aritméticas, no un modelo de lenguaje general. Todas las pruebas de esta rama deben pasar antes de publicar una distribución.

No existe todavía una firma de actualización compatible con la release 2.5.1 para esta rama.
